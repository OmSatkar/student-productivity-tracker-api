# Student Productivity Tracker API

A secure Spring Boot REST API project for managing student productivity, subjects, tasks, and attendance.

This project demonstrates backend development using Spring Boot, Spring Security, REST APIs, MySQL, and JPA/Hibernate.

---

## Features

- User Registration
- Spring Security Authentication
- Subject Management
- Task Tracking
- Attendance Management
- Dashboard APIs
- MySQL Database Integration
- REST APIs tested using Postman

---

## Tech Stack

- Java 17
- Spring Boot
- Spring Security
- Spring Data JPA
- Hibernate
- MySQL
- Maven
- Postman

---

## Project Modules

### Authentication Module
- User Registration
- Basic Authentication using Spring Security

### Subject Module
- Add Subjects
- View Subjects
- Update Subjects
- Delete Subjects

### Task Module
- Create Tasks
- Update Task Status
- Delete Tasks

### Attendance Module
- Mark Attendance
- View Attendance Records

### Dashboard Module
- Total Subjects
- Pending Tasks
- Completed Tasks
- Attendance Percentage
